# Dictionary App

I created a dictionary project in python that has 7 different features the user can try.
##  Calculations
These are the different calculations my project has:
1. avg. streams per song
   This takes an artist as a user input, then divides their total number of streams by their total number of tracks and returns that number.
2. top 3 songs % of total streams
   This one adds the total number of streams of the given artist's top 3 songs, then divides that number by the artist's total streams and returns the result.
3. ranking stats between artists
   This option has the user choose a stat and returns a list in order of high to low of each artist ranked on that stat.

## Challenges I Ran Into
A challenge I faced while creating my project was my third special feature (ranking stats). It was difficult to figure out how I was going to separate the different values from different artists and then subsequently format them into a readable list. I ended up doing some research and found out how to use lambda to my advantage, and implemented that into my code and it worked.
## What I'd Improve With More Time
If I had more time to work on this project, I would improve the ranking system so that I could rank my calculated stats between artists as well as the base stats that are already in the dictionary itself. I would also add the capability to add custom stats to every artist.
